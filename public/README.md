# Public Assets

## Recommended structure:

- /videos/
  - lab-hero.mp4   (short 8-15s muted looping video of the lab)

- /images/
  - See the detailed README inside /images/ and /images/team/ for exact filenames and guidelines.

  Key files:
  - hero-poster.jpg
  - og-image.png (1200×630)
  - team/ folder with 14 photos (9 current + 5 alumni)

## Notes
- Keep video file size reasonable (< 4MB) for fast page loads.
- All photography and video should respect lab safety (PPE) and privacy.
- Use tasteful, high-resolution imagery consistent with the clean academic aesthetic.

For production, optimize images using next/image or a service like Cloudinary.

## Current State (Team Photos)

Team and alumni cards use elegant monogram placeholders (initials + refined gradients) that look professional in both light and dark mode.

When you add real photos to `public/images/team/` using the exact filenames listed in `public/images/team/README.md`, they will automatically display — no code changes needed.
